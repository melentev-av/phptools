Reports problems found by PHPStan in PHP files.

The analysis runs the project's own PHPStan (vendor/bin/phpstan or the path from Settings | Tools | PHPStan), locally or via Docker Compose, with the project configuration (phpstan.neon, Larastan and so on). When to run it in the editor — while typing, on save or manually — is set in Settings | Tools | PHPStan.

Показывает ошибки, найденные PHPStan в PHP-файлах. Запускается PHPStan проекта (vendor/bin/phpstan или путь из Settings | Tools | PHPStan), локально или через Docker Compose, с конфигурацией проекта (phpstan.neon, Larastan и т.п.). Когда проверять в редакторе — при вводе, при сохранении или вручную — задаётся в Settings | Tools | PHPStan.
