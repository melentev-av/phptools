# PHPStan Integration for OpenIDE

Ошибки [PHPStan](https://phpstan.org) прямо в редакторе OpenIDE. Larastan и другие расширения подхватываются из конфигурации проекта.

> Плагин для OpenIDE. Работа в IDE JetBrains не поддерживается и не тестируется.

## Требования

- PHPStan в проекте (`composer require --dev phpstan/phpstan` или `larastan/larastan`) либо путь к бинарнику в настройках.
- Для проверки **без сохранения файла** — PHPStan **2.1.17+** или **1.12.27+** (опция `--tmp-file`). На более старых версиях плагин один раз предупредит и будет проверять файл после сохранения.
- В конфигурации (`phpstan.neon`) должен быть задан `level`, иначе его нужно выбрать в настройках: без уровня PHPStan не запускается.

## Как работает

- Проверяется только открытый файл, в рабочей папке ближайшего владельца `vendor/` — поэтому `phpstan.neon` / `phpstan.neon.dist` находятся сами.
- Ошибки подсвечиваются строкой; в подсказке — совет PHPStan (`tip`) и идентификатор ошибки со ссылкой на документацию phpstan.org.
- Ошибки уровня файла (без номера строки) показываются полосой над редактором.
- Quick-fix (Alt+Enter) «Игнорировать через @phpstan-ignore» добавляет `// @phpstan-ignore <identifier>` над строкой или дописывает идентификатор в уже существующий комментарий.
- Файлы из `excludePaths` пропускаются молча.
- Включается и выключается инспекцией **PHPStan validation** (Settings → Editor → Inspections → PHP tools); Code → Inspect Code тоже запускает PHPStan.

## Настройки

Settings → Tools → PHPStan. Хранятся в `.idea/phpstan-tools.xml` — файл можно коммитить.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Когда проверять | При вводе | «При вводе» (и несохранённые файлы), «При сохранении» или «Только вручную» (Inspect Code; панель — в следующей версии) |
| Бинарник | пусто | Пусто — `vendor/bin/phpstan` рядом с файлом и выше до корня проекта |
| Файл конфигурации | пусто | `-c`; пусто — PHPStan ищет сам |
| PHP-интерпретатор | пусто | Запуск как `<php> <phpstan>` |
| Доп. аргументы | пусто | Добавляются в командную строку |
| Таймаут | 60 с | Один запуск |
| Лимит памяти | `1G` | `--memory-limit` |
| Уровень | из конфигурации | Выбор доступен, только если в конфигурации уровня нет |

Кнопка **«Проверить»** запускает `phpstan --version` с текущими настройками — удобно для отладки Docker.

## Docker Compose / Laravel Sail

Включите «Запускать в Docker Compose» и укажите сервис. Для Sail:

| Настройка | Значение |
|---|---|
| Команда compose | `docker compose` |
| Сервис | `laravel.test` |
| Путь к проекту в контейнере | `/var/www/html` |

Плагин выполняет `docker compose exec -T -w <папка> laravel.test vendor/bin/phpstan ...` из корня проекта. Несохранённый файл передаётся во временный файл внутри контейнера, на хосте в проекте ничего не пишется.

## Встроенный PHPStan PHP-плагина

Если у PHP-плагина OpenIDE включена своя проверка PHPStan, при открытии проекта плагин предложит её выключить, чтобы ошибки не подсвечивались дважды.
