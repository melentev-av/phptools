Reports problems found by Psalm in PHP files.

The project's own Psalm runs (vendor/bin/psalm or the path from Settings | Tools | Psalm), locally or via Docker Compose, with the project configuration (psalm.xml). Psalm checks saved files only: unsaved changes are checked after saving.

Показывает проблемы, найденные Psalm в PHP-файлах. Запускается Psalm проекта (vendor/bin/psalm или путь из Settings | Tools | Psalm), локально или через Docker Compose, с конфигурацией проекта (psalm.xml). Psalm проверяет только сохранённые файлы: несохранённые изменения проверяются после сохранения.
