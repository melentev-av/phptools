Reports problems found by Phan in PHP files.

The project's own Phan runs (vendor/bin/phan or the path from Settings | Tools | Phan) with the project configuration (.phan/config.php), locally or via Docker Compose. Phan checks saved files only; by default the check runs on save because Phan parses the whole project every time.

Показывает проблемы, найденные Phan в PHP-файлах. Запускается Phan проекта с его конфигурацией (.phan/config.php), локально или через Docker Compose. Phan проверяет только сохранённые файлы; по умолчанию проверка идёт при сохранении, потому что Phan каждый раз разбирает весь проект.
