Highlights code that PHP-CS-Fixer would change, with the diff in the tooltip. Quick-fixes apply one change or the whole file right from the diff, without running the tool again.

The project's own PHP-CS-Fixer runs in dry-run mode with the project configuration (.php-cs-fixer.php / .php-cs-fixer.dist.php); files excluded by its Finder are skipped. Unsaved changes are checked too.

Подсвечивает код, который PHP-CS-Fixer поменял бы, с diff в подсказке. Quick-fix применяет одно изменение или весь файл прямо из diff, без повторного запуска. Запускается PHP-CS-Fixer проекта в режиме dry-run с конфигурацией проекта; файлы, исключённые в Finder, пропускаются. Несохранённые изменения тоже проверяются.
